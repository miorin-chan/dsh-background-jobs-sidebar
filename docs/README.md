# 开发与验证

[英文说明](../README.md) · [中文说明](../README.zh.md)

Host 从 `ctx.jobs` 读取启动时的任务，并订阅后续注册、停止和结算事件。
浏览器通过 DSH 的 Connection 接收仍在运行或正在停止的任务快照，连接在左侧边栏收起时关闭。
任务归属使用 DSH 的会话目录解析。`sidebar.footer.action` 在账号控件上方渲染任务区。
任务区占一整行。标题在没有任务时也能收起列表，之后开始的任务保持收起。
标题的颜色、悬停反馈和箭头图标与工作区文件树一致，运行计数紧跟标题并在大于 0 时使用强调色，
标题行右端留给侧栏的图标操作。

```sh
npm ci
npm test
npm run check
npm pack --dry-run --json
```

在工作区根目录运行脚手架校验：

```sh
node tools/new-dsh-plugin/cli.mts --check plugins/dsh-background-jobs-sidebar
```

实机检查使用一次性 profile。
先在两个会话启动限时后台任务，再从左侧边栏确认两项同时存在，点击一项返回所属会话，等待结算后核对计数。
对照文件树标题，确认两者起点、文字颜色和箭头一致，悬停只加深文字，用 Tab 聚焦标题时出现焦点环。
确认存在运行中或停止中任务时计数显示为强调色，数量回到 0 后恢复默认标题色。
没有任务时收起标题，再启动任务，确认列表保持收起、计数照常更新。
有任务时点击标题，检查高度、透明度和箭头的过渡。用键盘重新展开，确认折叠期间焦点会跳过任务条目。
在展开状态下添加与结算任务，确认条目和列表高度平滑变化，计数立即更新。
同时加载工作区文件插件。在高窗口和少量会话的情况下启动 8 条任务，确认文件窗格收起时能显示全部任务。
展开少量文件，再展开文件较多的目录，确认任务区按上方内容所需的空间调整高度。
展开更多会话或其他底部窗格，确认空间紧张时任务可在列表内滚动，账号控件仍可达。
收起这些窗格，确认任务列表恢复可用高度。在短窗口中用 Tab 聚焦任务列表，按 End 确认只滚动任务列表。
检查首条出现、末条消失和折叠期间的变化。开启系统的「减少动态效果」后，检查列表和箭头是否立即切换。
停用插件后，确认侧栏区块消失且原生的「新会话」仍可用。
